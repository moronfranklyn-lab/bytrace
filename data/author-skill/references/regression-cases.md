# 回归案例

## 使用边界

本文件只用于维护、验证和复盘 `xiaopu-writing`。它记录曾经真实暴露的问题与可验证的解决条件，不是新文章的结构模板，也不能把案例中的观点、长度、章节或配图数量机械复制到别的选题。

### 成文回归条件

- 明确区分全球前沿模型与国产模型前提，不能把 K3 写成全球最强模型。
- 从发布热点继续下钻到企业为何选择较便宜模型，并以“单次有效交付成本”解释产品机制。
- 读者问题链应从模型发布，进入成本经济学、企业产品决策、模型路由，再落到 AI 产品经理如何设计验收与升级机制；跨主题但共享同一个核心问题，不因章节多就误判跑题。
- 全文只保留一个主框架“单次有效交付成本”和一个辅助框架“模型任务路由”，不连续堆叠三组以上数字化方法论。
- 不以短为默认优点。后续段落只要继续增加理解、选择、行动或验证价值，就可以展开；删除重复，不删除收益。
- 第一人称可以直接代表小普表达已确认判断，但不能补造测试动作、失败记录和结果。
- 正文中的时间与版本使用“今年、去年、26年、这次”等自然说法；完整日期、版本与价格口径保留在内部证据记录。

### 主张证据回归条件

以下主张不能只靠文章级 `used_once` 自动通过：

| 主张 | 最低证据等级 | 当前预期 |
|---|---|---|
| 覆盖日常工作约 90% | `scenario_tested`，含代表任务集、样本与通过标准 | `evidence_pending` |
| 不宜单独承担大型项目 | `scenario_tested`，含代表任务、失败或人工接管边界 | `evidence_pending` |
| 国产模型下 K3＋V4 Flash 的默认路由 | 至少 `scenario_tested`；若声称长期最佳或胜过竞品则需 `controlled_comparison` | `evidence_pending` |

小普确认正文措辞只锁定内容，不会把这些门槛改成 `supported`。解决方式只有补证、缩小主张、改成个人当前选择或删除，不能添加“未同环境实测”免责声明代替。

### 视觉回归条件

- 封面必须使用固定 IP 资产，左标题、右主视觉，IP 为小比例角色锚点；人物是童话感二次元扁平笔绘，不能是真人照片或写实皮肤。
- 内文图先看信息作用。二元对立、流程和已闭合关系允许并通常应使用 `ip_role: none`；该值覆盖其他配图 Skill 的通用人物规则。
- `fig-01-enterprise-choice` 必须保持纯左右对立构图，不再写“小普 IP 辅助引导”。
- 同篇后续生成图必须记录已确认 Pilot 的路径与 SHA-256，只继承画风，不复刻构图。
- 默认手绘编辑插图采用暖白背景、黑色轻微抖动线、少量橙红；流程先物理化为轨道、闸门、扳手等具体动作。正式流程图、PPT 卡片墙、粉彩圆角卡片和精致商业扁平图均为视觉模式错误，应从零重生成。
- 原图和约 480 像素宽缩略图都要检查。主体组垂直居中，上下只留必要安全边距。
- 小普已接受 `fig-01` 底部留白偏多这一已知瑕疵。该图可保持 `ready`，但必须登记 waiver，并把垂直居中修正用于后续图片。

### 自动回归

在 Skill 维护源根目录运行：

```bash
python3 scripts/lint-article.py "../../文章/DeepSeek V4 Flash 没有惊艳我，但这个价格确实打穿了.md"
python3 scripts/validate-workspace.py --profile work "../../文章/临时工作区/20260801-deepseek-v4-flash-price"
```

两项应通过。发布检查：

```bash
python3 scripts/lint-article.py --publication "../../文章/DeepSeek V4 Flash 没有惊艳我，但这个价格确实打穿了.md"
python3 scripts/validate-workspace.py --profile release "../../文章/临时工作区/20260801-deepseek-v4-flash-price"
```

在真实证据、正式图片写回与状态未完成前，两项必须失败。若它们意外通过，说明发布闸门回归。

### 必须拦住的坏样本

- 文章级证据是 `used_once`，却把 90%、大型项目边界或长期路由标成已支持。
- 逐图 `ip_role: none`，占位或提示词仍要求“小普 IP 辅助引导”。
- 任务标成 `ready`，但成图文件不存在、像素未记录或 SHA-256 不匹配。
- 风格参考文件缺失或其 SHA-256 不匹配。
- 正式发布稿仍保留建议封面、建议配图占位或待配图状态。
- 一张图视觉模式已经错误，仍把失败图作为后续图片的风格参考。
- 用生成图冒充产品界面、执行日志或实测结果。
